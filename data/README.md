# Data manifest

Current data: three English synthetic practice scenarios and one fictional operator profile, authored for this project on 2026-10-03. They contain no real personal data and are not validated translations. Purpose: planning and prototyping, not proof of real-world model performance.

Reuse permission for these synthetic fixtures: team members may use, modify, and redistribute them as part of this project. No broader third-party dataset rights are implied.

Before adding external data, record dataset name, URL, version/date, license and restrictions, sample count, languages/dialects, consent/de-identification, intended use, and train/validation/test split. Review benchmark and model licenses separately. Never commit downloaded weights or private guest/learner records.

For local-language content, add native-speaker review status and date. Keep unreviewed machine translations explicitly labeled and out of accuracy claims.
