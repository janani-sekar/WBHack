About this demo

guest-i-mate is a Hospitality Coach prototype. Qwen runs on this computer after setup; no cloud fallback is used. This browser demo is not proof of on-phone inference. Learning data is stored in the local backend. AI feedback can be wrong: check facts and translations before accepting it. The scenarios are original synthetic examples, not interviews with real operators.

Your practice settings and history personalize the next session; model weights do not change. This demo is a single shared profile, so use example information only.
