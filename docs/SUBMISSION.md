# Submission checklist

Source: supplied Small AI for Development concept note, sections 5–9, printed pages 5–11; Tourism Annex C, printed pages 19–20. This summarizes the supplied brief, not a verified submission-portal form.

## Explicit deliverables
- [ ] Application through Hack-Nation's Global AI Hackathon website (the brief describes this as before the weekend).
- [ ] Working prototype, with its code or a link to it, by the end of the October 3–4, 2026 hackathon weekend.
- [ ] A **2–5 minute video**. The brief explicitly says entries without it will not make the shortlist.

The video must cover:
- One-sentence problem statement: Because of this tool, [user] will [action] by [when], which they otherwise would not do / do late / do worse; we know because [evidence].
- What AI does, why a simpler tool is insufficient, and guardrails.
- An end-to-end prototype demonstration (screen recording or slide-supported demonstration).
- Where the tool fits in the user's day and what happens next; technical stack details for technical builds.
- The team's perspective on what localizing AI development means.

## Required behavior and evidence
- [ ] Runs on a device already accessible to the intended user.
- [ ] Core feature works offline.
- [ ] Model files are small enough to sideload or transfer over weak connectivity; report actual size and provisioning steps.
- [ ] At least one interaction in a named local language, by voice or text.
- [ ] Explain what would change for a less-supported language.
- [ ] A person makes final decisions; uncertainty is surfaced rather than guessed away.
- [ ] Demonstrate a real use of AI on the chosen sector's task.
- [ ] Cite evidence for the problem with country, source, and year.
- [ ] Name build datasets, sources, licenses, sizes, and coverage limitations.
- [ ] Label synthetic data; check source terms independently.

## Rubric
| Criterion | Weight |
|---|---:|
| Built solution / Small AI fidelity | 25% |
| Development relevance and impact | 20% |
| Data grounding | 15% |
| Evidence it works | 15% |
| Clarity, design, inclusivity / AI value proposition | 15% |
| Scalability, replicability, next steps | 10% |
| Responsible AI, data, safety | Pass/fail |

## Recommended supporting artifacts, not separately mandated deliverables
- README with install/run instructions and model setup.
- Device benchmark, evaluation summary, known limitations, data/model manifest.
- Short pitch slides if useful; the supplied brief does not explicitly require a separate slide deck.
- Public or judge-accessible repository and video links. Public visibility is not explicitly required in the brief; verify portal rules.

## Verify in portal before submission
Exact cutoff time/timezone, submission URL, team fields, video hosting/file format, repository access, any required attachments, and whether applications are already complete. Do not infer an 11:59 PM deadline. This repository is not itself a completed submission.

Eligibility described by the brief: entrants aged 18–35. Shortlists October 5–6; one winner per sector; one representative per winning team invited to Seoul. Verify travel and passport/visa details with organizers.
